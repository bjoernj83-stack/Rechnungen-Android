Rechnungen – natives Android-Projekt

Die Rechnung läuft lokal in einer WebView. Der Druckbutton ruft über eine Android-JavaScript-Bridge den nativen Android PrintManager auf.
Im Android-Druckdialog kann entweder ein eingerichteter Drucker gewählt oder „Als PDF speichern“ verwendet werden.

Paket-ID: de.gokay.rechnungen
App-Name: Rechnungen

Zum Bauen: Projekt in Android Studio öffnen und Build > Build APK(s) verwenden.
